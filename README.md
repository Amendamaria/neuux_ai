# neuux_ai Setup Guide

## Running the Project

To run the neuux_ai project, you'll need to open two terminal windows/tabs and run the following commands:

### Terminal 1 - Client

```bash
cd client
npm i
npm run dev
```

### Terminal 2 - Server

```bash
cd server
npm i
npm run dev
```

## Steps Explanation

1. **Open two terminal windows** (or tabs) in your project root directory
2. **Terminal 1**: Navigate to the `client` folder, install dependencies, and start the development server
3. **Terminal 2**: Navigate to the `server` folder, install dependencies, and start the development server

Both servers should now be running concurrently for full application functionality.

---

**Note**: Make sure you're in the `neuux_ai` project root directory before running these commands.
